Summary

Image processing: resize, crop, rotate, color adjustments, blur, sharpen, overlay. Pure Go, backed by disintegration/imaging.

Functions, Macros, and Special Forms

  • average-hash

    Function v1.0 
    (average-hash img)

    Returns a 64-bit perceptual average hash as 16 hex characters.

  • base64

    Function v1.0 
    (base64 img format & quality)

    Encodes image and returns base64 text. Format: :png :jpeg :gif :bmp :tiff.

  • blur

    Function v1.0 
    (blur img sigma)

    Applies gaussian blur with given sigma.

  • bounds

    Function v1.0 
    (bounds img)

    Returns [x y width height] of image bounds.

  • brightness

    Function v1.0 
    (brightness img amount)

    Adjusts brightness. Range -100 to 100.

  • bytes

    Function v1.0 
    (bytes img format & quality)

    Alias for encode: returns encoded image bytes as a string. Format: :png :jpeg :gif :bmp :tiff.

  • contrast

    Function v1.0 
    (contrast img amount)

    Adjusts contrast. Range -100 to 100.

  • crop

    Function v1.0 
    (crop img x y width height)

    Crops region at x,y with given width and height.

  • crop-center

    Function v1.0 
    (crop-center img width height)

    Crops width×height from center of image.

  • data-uri

    Function v1.0 
    (data-uri img format & quality)

    Encodes image and returns a data:image/...;base64 URI.

  • decode

    Function v1.0 
    (decode data)

    Decodes image from byte string.

  • difference-hash

    Function v1.0 
    (difference-hash img)

    Returns a 64-bit perceptual difference hash as 16 hex characters.

  • encode

    Function v1.0 
    (encode img format & quality)

    Encodes image to bytes. Format: :png :jpeg :gif :bmp :tiff. Optional quality for JPEG.

  • fill

    Function v1.0 
    (fill img width height & anchor)

    Resizes and crops to fill exact width×height. Anchor: :center :top :bottom etc.

  • fit

    Function v1.0 
    (fit img width height)

    Resizes to fit within width×height preserving aspect ratio.

  • flip-h

    Function v1.0 
    (flip-h img)

    Flips image horizontally.

  • flip-v

    Function v1.0 
    (flip-v img)

    Flips image vertically.

  • from-rgba32

    Function v1.0 
    (from-rgba32 width height pixels)

    Creates an image from row-major packed RGBA integer pixels (0xRRGGBBAA).

  • from-rgba32-domain-fn

    Function v1.0 
    (from-rgba32-domain-fn width height xmin ymin dx dy pixel-fn)

    Creates an image by calling pixel-fn with continuous domain coordinates for each pixel. pixel-fn must return packed RGBA (0xRRGGBBAA).

  • from-rgba32-fn

    Function v1.0 
    (from-rgba32-fn width height pixel-fn)

    Creates an image by calling pixel-fn with x y for each pixel. pixel-fn must return packed RGBA (0xRRGGBBAA).

  • gamma

    Function v1.0 
    (gamma img value)

    Adjusts gamma correction. >1 brightens, <1 darkens.

  • grayscale

    Function v1.0 
    (grayscale img)

    Converts image to grayscale.

  • hash

    Function v1.0 
    (hash img)

    Returns the default perceptual image hash (currently difference-hash).

  • height

    Function v1.0 
    (height img)

    Returns image height in pixels.

  • invert

    Function v1.0 
    (invert img)

    Inverts image colors.

  • metadata

    Function v1.0 
    (metadata img)

    Returns image metadata map {:width :height :bounds :color-model}.

  • new

    Function v1.0 
    (new width height & color)

    Creates new image. Optional color as [r g b a] vector.

  • open

    Function v1.0 
    (open path)

    Opens an image file. Supports PNG, JPEG, GIF, BMP, TIFF, WebP.

  • overlay

    Function v1.0 
    (overlay base top x y & opacity)

    Overlays top image at x,y with optional opacity (0.0-1.0).

  • paste

    Function v1.0 
    (paste base top x y)

    Pastes image at x,y (no alpha blending).

  • pixel

    Function v1.0 
    (pixel img x y)

    Returns pixel color at x,y as [r g b a].

  • resize

    Function v1.0 
    (resize img width height)

    Resizes image to width×height. Use 0 for proportional.

  • rotate

    Function v1.0 
    (rotate img degrees)

    Rotates image by degrees (any angle). Background is transparent.

  • saturation

    Function v1.0 
    (saturation img amount)

    Adjusts saturation. Range -100 to 100.

  • save

    Function v1.0 
    (save img path)

    Saves image to file. Format detected from extension.

  • set-pixel!

    Function v1.0 
    (set-pixel! img x y color)

    Sets pixel x,y to color [r g b a]. Returns img.

  • sharpen

    Function v1.0 
    (sharpen img sigma)

    Sharpens image with given sigma.

  • sigmoid

    Function v1.0 
    (sigmoid img midpoint factor)

    Applies sigmoid contrast. Midpoint 0-1, factor controls steepness.

  • transpose

    Function v1.0 
    (transpose img)

    Transposes image (swap x and y axes).

  • transverse

    Function v1.0 
    (transverse img)

    Transverses image (rotate 270° then flip).

  • width

    Function v1.0 
    (width img)

    Returns image width in pixels.
