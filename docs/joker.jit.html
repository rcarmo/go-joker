Functions, Macros, and Special Forms

  • buffer-get

    Function v42.12.3 
    (buffer-get buffer index)

    Read one f64 buffer element. The index must be finite, integral and in bounds.

  • buffer-set!

    Function v42.12.3 
    (buffer-set! buffer index value)

    Write and return one f64 buffer element. Checks the index and rejects integers outside +/-2^53.

  • compile

    Function v1.0 
    (compile fn)

    Compiles a function to the fastest available execution path.
    For pure arithmetic fns, returns a native Go f64 closure.
    For other fns, returns an IR-compiled wrapper.

  • compile-wasm

    Function v1.0 
    (compile-wasm fn)
    

    (compile-wasm fn options)

    Compile a numeric function to WASM. Optional {:buffers [argument-indices]} selects checked f64 buffers and nested loops. Dense kernels return Double, reject integers outside +/-2^53, and never replay after a trap. Without options the existing scalar compiler is unchanged.

  • compiled?

    Function v1.0 
    (compiled? fn)

    Returns true if the function can be compiled to IR.

  • export-ir

    Function v1.0 
    (export-ir fn path)

    Compiles fn to Joker IR and writes a portable .ir JSON file to path.

    The file contains format/version metadata, numSlots, base64-encoded IR
    bytecode, serialized literal constants, and WASM eligibility metadata. It is
    intended for external runners/tooling that implement the go-joker IR ABI.

  • export-wasm

    Function v1.0 
    (export-wasm fn path)

    Compiles fn to a standalone numeric WASM module and writes raw .wasm bytes.

    The exported module exposes an `exec` function. Parameters and return values
    are i64 for integer IR programs or f64 for floating-point IR programs. Only
    pure WASM-eligible IR shapes can be exported this way; functions requiring
    Joker object/collection host imports should use export-ir instead.

  • info

    Function v1.0 
    (info fn)

    Returns a map with compilation information about a function.
    Keys: :compiled, :path, :slots, :captures, :self-recursive.

  • numeric-buffer

    Function v42.12.3 
    (numeric-buffer size)

    Allocate a checked f64 buffer of 0..1048576 elements for dense WASM kernels.
