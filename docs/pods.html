  • invoke

    Function v1.0 
    (invoke pod-id var args)
    

    (invoke pod-id var args opts)

    Synchronously invokes a pod var and returns its decoded result. Supports JSON, EDN, and Transit+JSON pod payloads; opts may include :timeout-ms.

  • load-pod

    Function v1.0

    (load-pod path-or-name version-or-args)
